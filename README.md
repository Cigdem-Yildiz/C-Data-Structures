# C Data Structures

Bu repo, C dilinde temel veri yapılarının çalışma mantığını öğrenmek ve pekiştirmek için hazırladığım örnekleri içerir. Her yapı, mantığını daha iyi anlamak için parçalara ayrılarak sade ve okunabilir şekilde implement edilmeye çalışılmıştır.

## Klasör Yapısı

Aşağıdaki yapı örnektir; içerik geliştikçe güncellenecektir.

```
C-Data-Structures/
└── linked-list/
```

## İçerik

### Linked List

- Tek yönlü bağlı liste
- Ekleme, silme, arama, gezme işlemleri
- Derste anlatılan örneklerin kendi yorumumla yeniden yazılmış versiyonları

### Eklenecek Yapılar

- Stack
- Queue
- Tree
- Heap
- Hash Table

## Amaç

- Veri yapılarının düşük seviyede nasıl çalıştığını anlamak
- Öğrendiğim konuları kendi kodumla pekiştirmek
- Her yapıyı adım adım öğrenirken düzenli bir çalışma alanı oluşturmak
- C’de hafıza yönetimi pratiği yapmak
- Temiz, anlaşılır ve sürdürülebilir implementasyonlar yazmak

## Kullanılan Araçlar

- MSYS2 / MinGW
- VS Code
